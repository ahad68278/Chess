C++ Command-Line Chess Game

A console-based implementation of Chess built in pure C++. It allows two players to play locally on an interactive 8x8 ASCII board with real-time move validation.

Key Features:

Interactive ASCII Board: Clean board layout rendered directly in the terminal.

Algebraic Input: Accept user inputs in coordinate format (e.g., E 2 E 4).

Piece Rules & Validation: Custom logic for Pawns, Rooks, Knights, Bishops, Queens, and Kings (including directional path-blocking checks and piece captures).

Turn System & Win Condition: Handles alternating turns between White and Black, ending when a King is captured.
